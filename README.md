## Notes for App Store / GDPR / CCPA

Even when an app collects no personal data, Apple still requires a publicly accessible Privacy Policy URL. This page states that:

- No personal information is collected, stored, transmitted, or shared  
- All data stays on-device  
- No third-party analytics / ads / tracking SDKs are used
